# AI 활용과정 강의 웹페이지

생성형 AI 활용 실무 4주 과정의 강의 자료 사이트.
50대 중심 수강생을 위해 **화이트 테마 · 큰 글씨 · 한 화면 한 가지**로 만들었습니다.
설계 배경과 원칙은 [DESIGN.md](./DESIGN.md) 참고.

## 실행

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # 프로덕션 빌드
```

## 화면

| 주소 | 내용 |
|---|---|
| `/` | 과정 소개, 준비물, 4주 커리큘럼 |
| `/week/1` | 1주차 강의 (슬라이드 14장) |
| `/week/2~4` | 준비 중 안내 |
| `/prompts` | 수업에서 쓴 프롬프트 복사 카드 모음 |
| `/instructor` | 강사 소개 |
| `/help` | 자주 막히는 지점 도움말 |

## 강의 내용 고치기

슬라이드는 전부 데이터 파일입니다. 컴포넌트를 건드릴 일이 거의 없습니다.

- `src/content/week-1.ts` — 1주차 슬라이드 + 강사 노트
- `src/content/course.ts` — 4주 과정 메타, 준비물
- `src/content/instructor.ts` — 강사 프로필 (**실제 정보로 교체 필요**)
- `src/content/help.ts` — 도움말

2주차를 추가하려면 `week-2.ts` 를 같은 모양으로 만들고 `course.ts` 의 `weeks` 에
넣은 뒤 `status: "ready"` 로 바꾸면 됩니다. 슬라이드 타입 목록은
`src/lib/deck-types.ts` 에 있습니다.

프롬프트에 빈칸을 두려면 `{{주제}}` 처럼 쓰고 `blanks: { 주제: "기본값" }` 을 주면
노란 칸으로 렌더되고, 수강생이 고친 값이 복사 결과에 반영됩니다.

## 강사 모드

헤더 오른쪽 끝 화면 아이콘을 누르면 켜집니다 (`?teacher=1` 로도 진입).
켜면 각 슬라이드에 진행 대본(멘트·시간·팁·자주 막히는 지점)이 붙고, 진행바에
소요 시간과 발표 화면(전체화면) 버튼이 생깁니다. 수강생 화면에는 보이지 않습니다.

키보드: `↓ / → / Space` 다음, `↑ / ←` 이전, `Esc` 목차 닫기.

### 발표 화면 (프로젝터)

강사 모드에서 진행바의 확대 아이콘을 누르면 켜집니다.

- 브라우저 전체화면 + 사이트 헤더·푸터 숨김 → 화면을 꽉 씁니다
- 기준 글자 22px, 본문 폭 56rem로 커져 뒷자리에서도 읽힙니다
- **강사 대본은 자동으로 숨겨집니다** — 발표 화면은 수강생이 보는 화면이라서요.
  대본을 보려면 발표 화면을 끄면 됩니다
- 다시 누르거나 `Esc` 로 빠져나옵니다

## 점검 스크립트

`pnpm dev` 를 띄운 상태에서:

```bash
node scripts/check-layout.mjs     # 모바일/데스크톱 캡처 + 가로 넘침·콘솔 오류
node scripts/check-behavior.mjs   # 복사·이동·목차·강사모드·글씨크기 동작
```

캡처 위치는 `SHOT_DIR` 환경변수로 바꿀 수 있습니다.
